# Google Play release kit — Help Me Cross

Package: `com.kinngshishupal.helpmecross` · Developer: KinngShishupal

Everything in `store/` and the launcher icons are generated by
`scripts/generate-brand.js` (see `art/README.md`).

## Before you upload (blockers)

- [ ] **Release signing.** Run `npm run keystore` once. It asks for a password, creates `~/keys/helpmecross-upload.keystore` (outside the repo) and registers it in `~/.gradle/gradle.properties`, which `android/app/build.gradle` reads. Back up the keystore and password: every future update must be signed with this key. Enroll in **Play App Signing** when creating the release, so a lost upload key can be reset.
- [x] **Real AdMob IDs.** The Android app ID is in `app.json`, and the banner and rewarded units are in `ANDROID_UNITS` in `src/ads.ts`. Debug builds always use test units. iOS stays on test IDs until it gets its own AdMob app.
- [x] **Relock stages.** Set `UNLOCK_ALL_STAGES = false` in `src/screens/HomeScreen.tsx`.
- [x] **Host the privacy policy.** Live at https://kinngshishupal.github.io/helpmecross/store/privacy-policy.html. Paste it into Play Console (App content → Privacy policy), and push again whenever `store/privacy-policy.html` changes.
- [ ] **Ad consent (EEA/UK/Switzerland).** AdMob requires a Google-certified consent message for users there. The app doesn't show one yet. Either add the UMP consent flow (supported by `react-native-google-mobile-ads`) or set up the consent message in AdMob → Privacy & messaging.
- [ ] **Build:** `npm run build:aab` creates `release/HelpMeCross-v<version>-<code>.aab` for Play. `npm run build:apk` creates an installable APK for testing on a phone. Raise `versionCode` in `android/app/build.gradle` before every new upload.

## App content answers

**Ads:** Yes, the app contains ads.

**Target audience:** choose **13 and over** (or 13–15, 16–17, 18+). If you include under-13 age groups, Google's Families policy applies. You would then have to stop using the Advertising ID, tag ad requests as child-directed and use only Families-certified ad settings. The code doesn't do any of that today.

**Content rating (IARC questionnaire):** no violence, sex, language, drugs or gambling. Note the "Missionaries & Cannibals" puzzle theme. It's cartoon, non-violent, and nothing is shown being harmed. Expect "Everyone" / PEGI 3.
